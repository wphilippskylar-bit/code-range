# Code Range

Read code effortlessly. 8 languages, each with its own locked beginner → elite path.
Offline-capable PWA for iPhone and laptop.

## Segments (independent tracks, each with its own 90% locks)
Linux/Bash · Windows (CMD + PowerShell) · **Windows Active Directory** · SQL · Python · JavaScript · C++ · Git · AI Prompting

Every step: a lesson, flashcards, explained questions (including predict-the-output), and
**real runnable labs**. Finish the labs and score **over 90%** on the gate to unlock the next step.
Each pass gives a checkpoint phrase — type it into Save → Restore on any device.

## You actually write and run code
- **Python, SQL, JavaScript** — real execution in the browser (Pyodide, SQLite/sql.js, a JS sandbox).
  Python and SQL download once on first use, then work offline.
- **Linux, Git** — a real filesystem + command sandbox and a real Git engine (commits, branches, merges, conflicts). Fully offline.
- **C++** — compiled by real g++ via an online compiler (needs internet).
- **Windows Active Directory** — a simulated domain controller you drive with real ActiveDirectory / GroupPolicy PowerShell cmdlets (users, groups, OUs, GPO links, Recycle Bin restore, security audit). Fully offline.
- **Windows (CMD/PowerShell basics), AI Prompting** — read-the-command drills / prompts checked against a rubric.
